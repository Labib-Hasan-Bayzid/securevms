\# 🔐 SecureVMS - Vulnerability Management System



\## Project Overview

A Dockerized web application for managing security vulnerabilities, bridging external consultants and internal security teams.



\## Features

\- ✅ User Registration (Internal/External)

\- ✅ Vulnerability Reporting with File Upload

\- ✅ MySQL 8 Database Integration

\- ✅ Persistent Storage for Files

\- ✅ Persistent Storage for Database

\- ✅ Multi-container Docker Deployment

\- ✅ Custom Docker Networking



\## Technologies Used

\- \*\*Backend:\*\* Python Flask

\- \*\*Database:\*\* MySQL 8.0

\- \*\*Containerization:\*\* Docker \& Docker Compose

\- \*\*Frontend:\*\* HTML5, CSS3



\## Docker Concepts Implemented

1\. Docker Images

2\. Dockerfile

3\. Docker Volumes

4\. Docker Networking

5\. Docker Compose

6\. Persistent Storage
